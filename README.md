 Global Electronics Sales & Retail Performance Dashboard

 📌 Overview
An interactive retail sales performance dashboard built using Microsoft Excel This project integrates global sales data, customer demographics, product catalog, and exchange rates to analyze business trends and store profitability.

🛠️ Tools & Technologies
- Microsoft Excel (Data Modeling, Advanced Pivot Tables, Dynamic KPIs, Excel Formulas)
- Data Visualization & UX/UI

💡 Key Features & Insights
- Integrated sales, products, store metrics, and exchange rates across multiple regions.
- Analyzed revenue trends, order quantities, and regional profitability.
- Interactive filtering with dynamic slicers for seamless exploration.
